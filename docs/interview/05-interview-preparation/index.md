# Question Bank & Mock Interviews

Bộ câu hỏi công khai này tập trung **phương pháp trả lời và điều hướng kiến thức**, không đóng khung Junior/Senior/Lead/Architect theo năm kinh nghiệm.

## 20 câu ưu tiên

| Nhóm | Câu hỏi |
| --- | --- |
| .NET | async/await vs Task.Run? DI lifetimes? value vs reference types? |
| API | 401 vs 403? REST idempotency? GraphQL N+1? |
| SQL | execution plan? composite index? optimistic concurrency? |
| Distributed | retry vs duplicate? Outbox? Event Hubs vs Service Bus? |
| Security | multi-tenant authorization? JWT validation? webhook signatures? |
| Azure | App Service vs Container Apps vs AKS? Managed Identity? |
| DevOps | deploy green nhưng revision NotReady? rollback với DB migration? |
| Architecture | modular monolith vs microservices? capacity planning? |
| Leadership | design review disagreement? mentoring? incident coordination? |

## Mẫu phỏng vấn 60 phút

- 5 phút: giới thiệu một sản phẩm/feature và phạm vi công việc.
- 15 phút: C#/.NET + API, giải thích runtime với ví dụ.
- 15 phút: SQL/concurrency/messaging, nói failure scenarios.
- 15 phút: System Design — hỏi requirements, chọn data model, draw components, defend trade-offs.
- 10 phút: Production troubleshooting, security, testing và mentoring.

**Rubric 0–4:** tính đúng, cơ chế, xử lý lỗi, evidence, communication. Không “đủ Senior” chỉ vì đọc trơn tru câu trả lời.
